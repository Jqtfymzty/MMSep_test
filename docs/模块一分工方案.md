# 模块一分工方案

## 测试对象

测试 `auto_eval.py`、`cache.py`、`mm_separators.py`。使用小样例、mock 和 CPU tensor，不依赖真实 API、GPU 或大模型权重。`software_test.py` 作为统一测试入口。

## 成员 A：`auto_eval.py` + `cache.py` 基础功能

### `auto_eval.py`

- 测试 `split_list()`、`get_chunk()` 和 `load_reference_and_answer()`。
- 测试文本/图像 prompt 是否包含问题、参考答案和模型答案。
- 测试 `parse_score()` 对整数、小数、缺少分数、分数数量错误和多余解释的处理。
- 测试答案文件不存在、JSONL 字段缺失、空文件和 API 异常。
- 编写不少于 10 条用例，使用 mock，不调用真实 Ark 服务。

### `cache.py` 基础功能

- 测试 `MMSepCache` 初始化、默认参数和非法参数。
- 测试首次写入和多次追加 Key/Value cache。
- 测试 `append_past_tok_ids()`、`set_kv_cache()`、`set_past_tok_ids()`。
- 测试 `__getitem__`、`__iter__`、`__len__`、`get_seq_length()` 和 `get_usable_length()`。
- 测试空 cache、单层/多层 cache、非法 layer index 和 tensor 维度错误。
- 编写不少于 8 条用例，并记录基础接口相关缺陷。

### 成员 A 交付物

- `auto_eval.py` 测试代码和最小 JSONL 样例；
- `cache.py` 基础功能测试代码和 tensor fixture；
- 不少于 18 条测试用例；
- 至少 1 个有效缺陷及修复验证；
- `software_test.py` 一键运行入口和 README 测试命令。

## 李晨希：`cache.py` 压缩功能 + `mm_separators.py`

### `cache.py` 压缩功能

- 测试 `compress_past_win_2_seps()` 对无分隔符、单个分隔符和多个分隔符的处理。
- 测试 `SEP_PADDING_IN_BATCH=True/False` 时，不同 batch 分隔符数量的 padding 或截断。
- 测试 `compress_kv_cache_and_tokids_layer_wise()` 和 `compress_kv_cache_and_tokids_noimg_layer_wise()`。
- 检查初始 cache、separator cache、local cache 的长度和拼接顺序。
- 测试 `SEP_ACCUMULATION`、`USE_MAX_SEP_CACHE` 和缓存达到上限后的行为。
- 测试 `update()` 在普通 token、文本分隔符、预填充阶段和视觉召回时返回的 KV cache。
- 编写不少于 8 条用例，使用固定的小尺寸 tensor。

### `mm_separators.py`

- 测试注意力排序后是否保留指定数量的视觉 token。
- 测试保留 token 是否保持原始顺序，以及 `visual_sep_pos` 是否正确。
- 测试 `position_ids`、`attention_mask` 和特征长度是否同步更新。
- 测试无图像 token、不同视觉 token 数量、不同 batch 和 padding 场景。
- 测试非法 `image_token_posi`、空 mask 和边界序列长度。
- 编写不少于 7 条用例。

### 李晨希交付物

- `cache.py` 压缩功能测试代码；
- `mm_separators.py` 测试代码和 tensor fixture；
- 不少于 15 条测试用例；
- 至少 2 个有效缺陷及修复验证；
- 缓存压缩和视觉 token 测试的执行结果。

## 两人共同完成

- 测试用例总数不少于 30 条，覆盖等价类、边界值、场景法中的至少两种。
- 共同检查 `cache.py` 的基础功能与压缩功能是否能串联运行。
- 互相运行对方测试，确认缺陷可以复现，修复后可以回归通过。
- 完成测试用例 Excel、缺陷清单、测试报告、PPT 和演示视频。
- 报告记录测试命令、通过数量、失败数量、环境信息和成员贡献度。
- 每人使用自己的 Git 账号提交，提交记录应能对应本人负责的代码和文档。

## 执行顺序

1. 成员 A 搭建统一入口和评估样例，李晨希准备缓存与视觉 tensor fixture。
2. 两人分别编写正常、边界和异常测试。
3. 先运行各自测试，再运行全部测试，记录并复现缺陷。
4. 修复后进行回归测试，合并文档并录制演示视频。

## 完成标准

一条命令可运行全部测试；测试用例不少于 30 条；有效缺陷不少于 3 个且完成验证；测试不依赖联网、API key、GPU 或大模型权重。
